# Vault Write-up 

Challenge Source: [Vault Tarte Tatin](https://hackropole.fr/fr/challenges/reverse/fcsc2019-reverse-vault/) 


# Solution

I use IDA to decompile the challenge and reverse it.

See the script "vault.py" to get the solution.

```bash
└─$ ./vault.txt
=-=-=-= Very secure vault =-=-=-=
Please enter you very secure password:
\o/ Access granted! \o/
Here is your flag: ECSC{346bc605be4ed8361a68a3d9748fc9b87de397e1}

```

✅ **Answer**: ECSC{346bc605be4ed8361a68a3d9748fc9b87de397e1}
